# BUHAR.co — Premium Elektronik Sigara Mağazası 🔮💨

Türkçe arayüze sahip, modern ve şık bir elektronik sigara / e-likit satış uygulaması.
Next.js 15 (App Router), React 19 ve Tailwind CSS v4 ile geliştirildi.

## ✨ Özellikler

- 🎨 **Modern tasarım** — aurora arka plan, glassmorphism, neon gradyanlar ve animasyonlar
- 🔞 **18+ yaş doğrulama** kapısı (localStorage)
- 🛒 **Çalışan sepet** — ekle / çıkar / adet, ücretsiz kargo eşiği, drawer
- 🔍 **Kategori filtreleme** — pod, kit, likit, tek kullanımlık, aksesuar
- ⭐ **Ürün kartları** — puan, yorum, indirim etiketleri, teknik özellikler
- 💬 Müşteri yorumları, bülten kaydı ve yasal uyarılar
- 📱 Tamamen responsive

## 🚀 Geliştirme

```bash
npm install
npm run dev      # http://localhost:3000
npm run build    # production build
```

## ☁️ Vercel'e Dağıtım

Bu proje sıfır yapılandırma ile Vercel'e dağıtılabilir. Reponun
import edilmesi yeterlidir; Next.js otomatik algılanır.

## ⚠️ Yasal Uyarı

Bu ürünler yalnızca **18 yaş ve üzeri** yetişkinler içindir. Sigara ve
nikotin içeren ürünler sağlığa zararlıdır ve bağımlılık yapar. Bu proje
tasarım/demo amaçlıdır.
